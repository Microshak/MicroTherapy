Quick-reference guides for each therapeutic approach. Read the relevant file
when the router selects a modality.

| Modality | File | Best For |

| ACT | `act.md` | Fighting thoughts, rumination, values disconnection |
| DBT | `dbt.md` | Emotional overwhelm, impulsivity, interpersonal conflict |
